# TP-Link TL-MR3020 — прашыўкі і інструкцыя па ўсталёўцы

Рэпазітoрый змяшчае файлы прашывак і пакрокавую інструкцыю па перапрашыўцы кішэннага роўтара **TP-Link TL-MR3020**.

## Змест

- 📦 **Файлы прашывак** (`.bin`) — гатовыя вобразы для ўсталёўкі праз вэб-інтэрфейс роўтара або аднаўлення праз TFTP
- 📖 **Інструкцыя па ўсталёўцы** — пакрокавае кіраўніцтва па прашыўцы прылады
- 🔧 Заўвагі па аднаўленні пасля няўдалай прашыўкі (recovery праз TFTP-сервер)

## Хуткі старт

1. Вызначце версію свайго роўтара (пазначана на налепцы знізу прылады)
2. Спампуйце адпаведны файл прашыўкі з рэпазіторыя
3. Прытрымлівайцеся інструкцыі для ўсталёўкі праз вэб-інтэрфейс (`Сістэмныя прылады → Абнаўленне ПЗ`) або праз TFTP-recovery, калі роўтар не загружаецца

## Аднаўленне праз TFTP (калі роўтар "акірпічыўся")

Каротка: заціснуць кнопку RESET/WPS пры ўключэнні сілкавання, падняць TFTP-сервер з файлам прашыўкі ў корані, дачакацца перадачы файла — роўтар сам загрузіць вобраз.

## Папярэджанне

⚠️ Перапрашыўка выконваецца на ваш уласны рызык. Няправільная прашыўка альбо адключэнне сілкавання ў працэсе можа прывесці да непрацаздольнасці прылады.
