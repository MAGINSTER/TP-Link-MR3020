# TP-Link TL-MR3020 — прошивки и инструкция по установке

Репозиторий содержит файлы прошивок и пошаговую инструкцию по перепрошивке карманного роутера **TP-Link TL-MR3020**.

## Содержимое

- 📦 **Файлы прошивок** (`.bin`) — готовые образы для установки через веб-интерфейс роутера или восстановления через TFTP
- 📖 **Инструкция по установке** — пошаговое руководство по прошивке устройства
- 🔧 Заметки по восстановлению после неудачной прошивки (recovery через TFTP-сервер)

## Быстрый старт

1. Определите версию своего роутера (указана на наклейке снизу устройства)
2. Скачайте подходящий файл прошивки из репозитория
3. Следуйте инструкции для установки через веб-интерфейс (`Системные инструменты → Обновление ПО`) или через TFTP-recovery, если роутер не загружается

## Восстановление через TFTP (если роутер "окирпичился")

Кратко: зажать кнопку RESET/WPS при включении питания, поднять TFTP-сервер с файлом прошивки в корне, дождаться передачи файла — роутер сам загрузит образ.

## Предупреждение

⚠️ Перепрошивка выполняется на свой риск. Неправильная прошивка или отключение питания в процессе может привести к неработоспособности устройства.
