# TP-Link TL-MR3020 — прошивки та інструкція з встановлення

Репозиторій містить файли прошивок та покрокову інструкцію з перепрошивки кишенькового роутера **TP-Link TL-MR3020**.

## Вміст

- 📦 **Файли прошивок** (`.bin`) — готові образи для встановлення через веб-інтерфейс роутера або відновлення через TFTP
- 📖 **Інструкція з встановлення** — покрокове керівництво з прошивки пристрою
- 🔧 Нотатки щодо відновлення після невдалої прошивки (recovery через TFTP-сервер)

## Швидкий старт

1. Визначте версію свого роутера (вказана на наклейці знизу пристрою)
2. Завантажте відповідний файл прошивки з репозиторію
3. Дотримуйтесь інструкції для встановлення через веб-інтерфейс (`Системні інструменти → Оновлення ПЗ`) або через TFTP-recovery, якщо роутер не завантажується

## Відновлення через TFTP (якщо роутер "закирпичився")

Коротко: затиснути кнопку RESET/WPS під час увімкнення живлення, підняти TFTP-сервер із файлом прошивки в корені, дочекатися передачі файлу — роутер сам завантажить образ.

## Попередження

⚠️ Перепрошивка виконується на власний ризик. Неправильна прошивка або відключення живлення в процесі може призвести до непрацездатності пристрою.
